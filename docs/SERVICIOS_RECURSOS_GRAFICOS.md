# Recursos gráficos para Servicios

El sitio ya utiliza ilustraciones existentes y la imagen aprobada de Páginas web. Las siguientes imágenes son opcionales y permitirían dar una ilustración propia y de mayor resolución a cada servicio.

## Indicaciones comunes

- Ilustración tecnológica 3D limpia, coherente con el inicio de BaseLogic: azul eléctrico, celeste, cian, blanco y sombras suaves.
- Formato horizontal 16:9; idealmente 1600 × 900 píxeles o superior. Entregar en WebP o PNG de buena calidad.
- Fondo claro e integrado con la ilustración. Mantener el elemento principal cerca del centro para que funcione en recortes de escritorio y móvil.
- Sin textos, cifras, marcas de terceros, logotipos inventados ni datos que puedan confundirse con resultados reales.
- Dejar la imagen libre de títulos y botones: esos elementos se incorporan en la web como texto accesible.

## Imágenes sugeridas

| Archivo sugerido | Página | Escena para generar |
|---|---|---|

| `landing-pages-hero.webp` | Landing pages | Una página digital enfocada en una sola oferta, con un botón de acción abstracto, cursor y teléfono. La acción debe entenderse sin palabras. |

  | `automatizacion-hero.webp` | Automatización | Un flujo de tareas conectado entre formulario, engranaje y notificación, con conexiones claras y pocos elementos. |

Se pueden guardar en `public/images/servicios/`. La imagen de Páginas web actualmente proviene de una selección aprobada del proyecto; si se prefiere una familia completamente ilustrada, también se puede crear una versión 3D para esa página con la misma dirección visual.
